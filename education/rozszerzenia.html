1. Granica proporcji złotego jaja1. The golden egg ratio limit

Tniemy powierzchnię z·r = 1 płaszczyzną o nachyleniu ściany piramidy. Przekrój to owal o długości L i szerokości W. Gdy przesuwamy płaszczyznę wyżej (większe z₀), owal maleje, a jego proporcja L/W zbliża się do granicy S/A = √(1+t²), gdzie t = h/A. Dla 11:7 ta granica jest o 0,034% powyżej φ, więc samo L/W nigdy nie osiąga φ — zbliża się do niej, zatrzymując się tuż nad nią.

We cut the surface z·r = 1 with a plane tilted like the pyramid's face. The section is an oval of length L and width W. Moving the plane higher (larger z₀) makes the oval smaller, and its ratio L/W approaches the limit S/A = √(1+t²), where t = h/A. For 11:7 that limit is 0.034% above φ, so L/W itself never reaches φ — it gets closer and stops just above it.

Dowód i szczegółyProof and details

Na płaszczyźnie z = z₀ + t·x punkt powierzchni spełnia (z₀ + t·x)²(x² + y²) = 1. Krańce owalu (y = 0) to x(z₀ + t·x) = ±1, czyli a, b = (−z₀ ± √(z₀² ∓ 4t))/(2t); owal istnieje tylko dla z₀² > 4t (dla 11:7: z₀ > 2,256304299271). Długość w płaszczyźnie L = (b − a)·√(1 + t²); szerokość W = 2·max y, gdzie maksimum spełnia x(z₀ + t·x)³ + t = 0.

Dla dużego z₀ mamy b − a ≈ 2/z₀ i W ≈ 2/z₀, więc L/W → √(1 + t²) = S/A, bo t = h/A. Przy 11:7: S/A = 1,618590346797; z₀ = 7,65: L/W = 1,619742961 (0,1056% od φ); z₀ = 15,3: 1,618662132; z₀ = 30,6: 1,618594832. Owal rysujemy w jego płaszczyźnie w jednej skali — to nie elipsa. Złotą granicę S/A = φ dałoby nachylenie θ = 51,827292373°, a 11:7 ma 51,842773413°.

On the plane z = z₀ + t·x a surface point satisfies (z₀ + t·x)²(x² + y²) = 1. The oval's ends (y = 0) are x(z₀ + t·x) = ±1, i.e. a, b = (−z₀ ± √(z₀² ∓ 4t))/(2t); the oval exists only for z₀² > 4t (for 11:7: z₀ > 2.256304299271). Length in the plane L = (b − a)·√(1 + t²); width W = 2·max y, where the maximum satisfies x(z₀ + t·x)³ + t = 0.

For large z₀, b − a ≈ 2/z₀ and W ≈ 2/z₀, so L/W → √(1 + t²) = S/A because t = h/A. For 11:7: S/A = 1.618590346797; z₀ = 7.65: L/W = 1.619742961 (0.1056% from φ); z₀ = 15.3: 1.618662132; z₀ = 30.6: 1.618594832. The oval is drawn in its own plane at one scale — it is not an ellipse. A golden limit S/A = φ would need a slope θ = 51.827292373°; 11:7 has 51.842773413°.

2. Kula wpisana i złoty podział2. Inscribed sphere and the golden section

Do piramidy można włożyć jedną największą kulę dotykającą podstawy i wszystkich czterech ścian. W przekroju przez środek to okrąg wpisany w trójkąt o bokach podstawy i dwóch apotemach. Jego środek I dzieli wysokość tak, że VI/OI = S/A — to ta sama proporcja co wcześniej, więc to ta sama rodzina φ, a nie nowe, niezależne potwierdzenie.

One largest sphere fits inside the pyramid, touching the base and all four faces. In the central section it is the circle inscribed in the triangle formed by the base and two apothems. Its centre I divides the height so that VI/OI = S/A — the same ratio as before, so it is the same φ family, not a new independent confirmation.

Dowód i szczegółyProof and details

W przekroju osiowym trójkąt ma podstawę B, wysokość h i boki S = √(A² + h²), A = B/2. Promień okręgu wpisanego to pole przez połowę obwodu: r = A·h/(A + S). Dwusieczna kąta przy M przecina oś w I, więc z twierdzenia o dwusiecznej VI/OI = MV/MO = S/A. Punkt styczności T leży na MV; styczne z M są równe, więc MT = MO = A i VT = S − A.

Dla 11:7: r = 2,673193998658; VI/OI = 1,618590346797 (0,0344% od φ); MT = 5,5; VT = 3,402246907; MT/VT = 1,616578735 (0,0899% od φ); VI/VO = 0,618115143.

In the axial section the triangle has base B, height h and sides S = √(A² + h²), A = B/2. The inradius is area over semi-perimeter: r = A·h/(A + S). The bisector of the angle at M meets the axis at I, so by the angle-bisector theorem VI/OI = MV/MO = S/A. The tangency point T lies on MV; tangents from M are equal, so MT = MO = A and VT = S − A.

For 11:7: r = 2.673193998658; VI/OI = 1.618590346797 (0.0344% from φ); MT = 5.5; VT = 3.402246907; MT/VT = 1.616578735 (0.0899% from φ); VI/VO = 0.618115143.

3. Dlaczego proporcja 11:7?3. Why the 11:7 ratio?

Jedno nachylenie daje naraz dwie wartości: 2B/h (blisko π) i S/A (blisko φ). Spośród ułamków o mianowniku do 20 tylko 11/7 mieści się jednocześnie w przedziale 0,1% wokół obu celów. To fakt arytmetyczny o małych ułamkach, nie argument o zamiarze.

One slope gives two values at once: 2B/h (near π) and S/A (near φ). Among fractions with denominator up to 20, only 11/7 falls inside the 0.1% window around both targets. This is an arithmetic fact about small fractions, not an argument about intent.

Dowód i szczegółyProof and details

Dla q = B/h: 2B/h = 2q, a S/A = √(1 + 4/q²). Warunek 0,1% wokół π daje q ∈ [1,569225530, 1,572367123]; wokół φ: q ∈ [1,569763608, 1,574851708]. Wśród p/q′ z q′ ≤ 20 w obu przedziałach leży tylko 11/7. Ułamki łańcuchowe nachylenia t = h/A: cel φ wymaga t = √φ = [1; 3, 1, 2, 11, 3, …], cel π wymaga t = 4/π = [1; 3, 1, 1, 1, 15, …]. Redukt [1; 3, 1, 2] = [1; 3, 1, 1, 1] = 14/11 jest wspólny dla obu rozwinięć, a t = 14/11 odpowiada dokładnie B:h = 11:7. Następne wyrazy (11 oraz 15) są duże, dlatego to krótkie przybliżenie jest tak dobre. 11:7: 2B/h = 3,142857143 (0,0402% od π), S/A = 1,618590347 (0,0344% od φ).

For q = B/h: 2B/h = 2q and S/A = √(1 + 4/q²). The 0.1% window around π gives q ∈ [1.569225530, 1.572367123]; around φ: q ∈ [1.569763608, 1.574851708]. Among p/q′ with q′ ≤ 20 only 11/7 lies in both windows. Continued fractions of the slope t = h/A: the φ target needs t = √φ = [1; 3, 1, 2, 11, 3, …], the π target needs t = 4/π = [1; 3, 1, 1, 1, 15, …]. The convergent [1; 3, 1, 2] = [1; 3, 1, 1, 1] = 14/11 is shared by both expansions, and t = 14/11 is exactly B:h = 11:7. The next terms (11 and 15) are large, which is why this short approximation is so good. 11:7: 2B/h = 3.142857143 (0.0402% from π), S/A = 1.618590347 (0.0344% from φ).
