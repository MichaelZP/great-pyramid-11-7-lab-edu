Co pokazuje model / What the model shows

1. Rzeczywisty przekrój powierzchni z·√(x²+y²)=1 płaszczyzną z=z₀+t·x, t=h/A, w jego własnej płaszczyźnie i jednej skali (bez elipsy). Suwak z₀; dla z₀² ≤ 4t owalu nie ma. L/W maleje ku S/A=√(1+t²); linia przerywana ma długość L/(S/A). / The true section in its own plane, one uniform scale, no ellipse. For z₀² ≤ 4t there is no oval. L/W decreases toward S/A; the dashed line has length L/(S/A).

2. Kula wpisana: r = A·h/(A+S), środek I, punkt styczności T na apotemie MV. VI/OI = S/A, MT = A, VT = S−A. / Inscribed sphere: centre I, tangency point T on the apothem MV.

3. 2B/h i S/A dla 3:2, 8:5, 11:7, 14:9, 19:12, 25:16 — ten sam błąd |R−c|/|c|. / The same relative error for six small ratios; ordered by denominator, not a ranking.

Model matematyczny; zgodności liczbowe nie dowodzą intencji budowniczych. / A mathematical model; numerical agreements do not establish builders' intent.
